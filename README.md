# Early Diagnosis for Alzheimers' Disease
## PreliminaryData Collection Utility Tool

Data Collection for Alzheimers' Patients for Artificial Intellegence Dataset Training

Data will be cross-checked with known reliable patient data to train an AI Dataset, corresponding varying degrees of known human features to varying degrees of Alzheimers' severity.

End product (std deployment) tests will be less stringent and will be lighter on system resources.
